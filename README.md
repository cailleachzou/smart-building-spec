# 建筑智能化技术方案模板

> 弱电智能化方案通用框架，基于实际项目经验沉淀。

## 文件结构

```
00-通用模板/
├── 00-概况.md              # 项目总览（甘特图/架构图）
├── 01-项目概述.md          # 工程概况
├── 02-工程范围与服务.md    # 承包范围
├── 03-子系统配置表.md      # 配置矩阵
├── 10-安防系统/           # CCTV / 门禁 / 入侵报警 / 停车场等
├── 20-基础设施/           # 综合布线 / 计算机网络 / 机房 / UPS
├── 30-楼控与能源/          # BA / 能耗计量 / 智能照明
├── 40-音视频与会议/        # 背景音乐 / 信息发布 / 会议系统
├── 50-其他子系统/          # 电梯控制 / 对讲 / 工位 / 客控等
└── 60-平台软件/            # IBMS / 软件招标参数
```

## 使用说明

1. 复制 `00-通用模板` 文件夹到新项目目录下
2. 将 `[项目名称]` 等占位符替换为实际项目信息
3. 根据项目业态增删子系统模块
4. 技术参数按实际需求调整
5. 导出 PDF/DOCX 时复制到外部项目文件夹
