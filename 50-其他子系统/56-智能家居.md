# 智能家居系统

> 所属分类：其他子系统
> 相关系统：[[55-客控系统]] / [[00-概况]]

## 系统概述

智能家居系统用于住宅/公寓区域，控制内容包括灯光控制、电动窗帘控制、风机盘管空调控制。

## 系统架构

- 智能家居系统采用分布式总线控制系统
- 各类控制模块、智能面板、感应器等设备间采用系统总线相连
- 总线长度可达1000米
- 各类控制模块、智能面板、感应器都内置CPU
- 不得采用主从型设备和控制系统，任何一个设备损坏均不影响其它设备正常运行

## 功能要求

1. 智能家居系统应具有开放的控制协议
2. 能与空调、电动窗帘等设备进行集成

## 系统主要设备参数

### CAN智能网关

| 参数 | 要求 |
|------|------|
| 工作电压 | DC24V |
| 额定功率 | 3W |
| 通讯接口 | 2个CAN、3个RS485、1个以太网 |

### 智慧中控屏

| 参数 | 要求 |
|------|------|
| CPU | 多核高性能CPU |
| SDRAM | 1G |
| FLASH | 8GB |
| 系统 | Android 10.0 |
| 液晶屏 | 10.1吋 分辨率1280*800 |
| 通讯接口 | 以太网、WIFI、蓝牙4.2、ZigBee、RS485 |

### 窗帘电机（弱电控制）

| 参数 | 要求 |
|------|------|
| 工作电压 | AC110~240V，50/60Hz |
| 额定扭矩 | 1.2N.m |
| 安全载重 | 50kg |
| 运行速度 | 14cm/s |
