# 无线对讲系统

> 所属分类：其他子系统
> 相关系统：[[00-概况]]

## 系统概述

无线对讲系统为保安无线对讲系统，用于保安人员之间的通讯联络。

## 系统架构

系统采用数字中继台组网方式，支持数字 TDMA 模式下 2 个同步语音或数据信道。

## 系统主要设备参数

### 数字中继台

| 参数 | 要求 |
|------|------|
| 频率范围 | UHF1:350-400MHz；UHF2:400-470MHz |
| 区域容量 | 每组最多32个信道 |
| 信道容量 | ≥4 |

### 合路器

| 参数 | 要求 |
|------|------|
| 频段 | 410MHz-430MH，450MHz-470MHz |
| 插损 | ≤3.2dB |
| TX-TX隔离度 | ≥80dB |

### 双工器

| 参数 | 要求 |
|------|------|
| 频率范围 | 400～470MHz |
| 插入损耗 | ≤1.8dB |
| 收发隔离 | ≥80 dB |

### 室内全向吸顶天线

| 参数 | 要求 |
|------|------|
| 频率范围 | 400～470MHz |
| 增益 | 2±3dB |
| 输入端口电压驻波比 | 1:1.25 |

### 手持对讲机

| 参数 | 要求 |
|------|------|
| 频率范围 | UHF:400-470 MHz |
| 信道间隔 | 6.25KHz/ 12.5KHz / 25KHz |
| 信道容量 | 16 |
| 声码器类型 | AMBE+2 |
