# 会议系统

> 本文档为摘要版，完整原始规格请参阅：[[附件-[项目名称]技术规格书-会议]]

> 所属分类：音视频与会议
> 相关系统：[[40-背景音乐]] / [[41-信息发布]] / [[00-概况]]

## 系统概述

多媒体会议系统包含3F多功能厅等区域的建设。

### 系统组成
1. 音频扩声系统
2. 同声传译系统
3. 视频系统
4. LED显示系统
5. 集中控制系统
6. 会议预约系统
7. 舞台灯光系统

## 音频扩声系统

### 主要设备参数

| 设备名称 | 主控参数 |
|----------|----------|
| 有源数字可调式柱式音箱 | 全频系统，不少于6x6"低频驱动器，频率响应范围优于90Hz-19kHz，水平覆盖角度范围不小于140°±10°，最大声压级不小于130 dB |
| 18寸有源超低音箱 | 单元尺寸：不小于1x18"驱动器，频率下限：不高于35Hz，最大声压级：不小于130dB |
| 二分频同轴吸顶音箱 | 驱动单元：不小于1 x 8 "低音单元，频率响应：不劣于60Hz-20kHz(-10dB) |
| 数字调音台 | 输入通道不少于48路全处理输出通道32路，主控彩色液晶屏触摸屏不小于7' |
| 数字音频处理器 | 不少于4路话筒/线路电平输入，不少于4路话筒/线路电平输出，不少于8路AEC通道 |

## 同声传译系统

### 主要设备参数

| 设备名称 | 主控参数 |
|----------|----------|
| 8通道数字红外发射主机 | 符合 ISO 22259 国际标准，DQPSK数字调制/解调技术 |
| 35W数字红外辐射单元 | 符合 GB 50524-2010，设备辐射范围≥96米 |
| 8通道数字红外接收机 | 按钮式通道选择，可接收不少于8个音频通道，270°超宽接收角度 |

## 视频系统

1. 视频分布式通过IP网络实现视频信号的传输切换
2. 高清云视频会议
3. 支持无线投屏方式，支持市面上所有产品及个人移动办公设备

## 语音转写一体机

1. 私有化部署,纯内网环境使用
2. 实现对中文普通话连续语音的实时转写
3. 音频转写效率可达1:6
4. 支持对音频文件中的说话人进行分离,支持不少于8个说话人识别
5. 支持实时会议速记、会议纪要模块
