## 智能化集成平台

### 物联网关

#### 整体要求

边缘节点采用IoT平台软件系统，实现边缘与各子系统、边缘与云端协同能力。IoT平台是软硬件一体化工业级IoT操作系统，致力于将复杂多样的智能化设备通信协议经过数据清洗整合，设备点位模型化，事件订阅配置器，转换输出成标准易用的协议，包含HTTP、MQTT等。

#### 接入能力

投标人提供的物联网接入系统具备以下协议类型的对接能力：

1. **BACnet类型**：BACnet IP方式、BACnet MS/TP、BACnet Ethernet、BACnet ARCNET、BACnet PTP
2. **Modbus类型**：Modbus TCP、Modbus RTU、Modbus ASCII、Modbus DTU
3. **OPC类型**：OPC DA（2.x版本）、OPC UA（3.x版本）
4. **SNMP类型**：简单网络管理协议
5. **通用协议**：RS485、RS232、Socket TCP、Socket UDP、Web Service/XML/JSON、HTTP/REST/JSON、DLL动态链接库、ODBC、KNX等

### 首页设置

1. 服务调用可显示调用次数、平均响应时间、成功率
2. 事件推送可显示调用次数、平均响应时间、成功率
3. 服务运行状态可通过表格形式显示各服务按服务名称、设备分类、状态、调用次数、成功率
4. 定时任务调度状态可通过表格形式显示任务名称、任务分组、状态、启用状态

### 配置管理

1. **设备信息**：支持填写excel模板批量导入设备数据
2. **设备分类**：以树状结构呈现系统中所有设备分类和分类层级
3. **设备型号**：为设备模型设置提供基础数据
4. **设备库模型**：为设备分类配置模型属性值
5. **点位导入**：用于对设备点位的管理，支持通过模板下载批量导入
6. **服务管理**：用于配置服务对应品牌和型号信息
7. **协议管理**：对特定分类、特定品牌下的某一设备型号配置对应的协议
8. **授权管理**：用于配置外部应用访问物联网平台时调用的服务接口

### 系统管理

1. **调度配置**：用于管理系统中各类的自动任务
2. **菜单管理**：支持对功能内容进行个性化配置
3. **部门管理**：用于管理用户的所属部门信息
4. **常用配置**：支持新增、编辑和删除常用配置信息
5. **数据字典**：用于管理系统中所有的数据类型

### 智慧平台

#### 平台总述

智慧平台是整个智能化系统的核心管理平台，实现对各子系统的统一管理和数据整合。

#### 基础服务模块

1. 用户管理
2. 权限管理
3. 角色管理
4. 组织架构管理
5. 日志管理
6. 系统配置

#### 运维服务中心

1. 设备管理
2. 故障管理
3. 维护管理
4. 巡检管理

#### 能耗管理中心

1. 能耗监测
2. 能耗统计
3. 能耗分析
4. 报表管理

#### 集成子系统功能模块

各子系统的功能管理模块，包括但不限于：
- 视频监控管理
- 门禁管理
- 报警管理
- 设备监控
- 智能照明
- 环境监测
